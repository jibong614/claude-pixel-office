1.9.16: 기본 아이콘 office_a 개편&선택 기능 & 업데이트 주기 1시간 단축 & 세션 이동 시 Claude 데스크톱 앱 지원 & 산책모드 슬림화 & 설정 7대 카테고리 개편 & 직원 성별 커스텀

- 업데이트 확인 주기 12시간 ➔ 1시간(기본값)으로 대폭 단축 및 설정(시스템 탭)에 확인 주기(1시간/5시간/12시간) 콤보 선택 옵션 추가
- 구버전 아이콘 폐기 및 office_a를 기본 실행 파일 아이콘으로 지정, 설정(화면 탭)에서 아이콘(A/B/C) 선택 및 확인 후 프로그램 자동 재실행 기능 탑재
- 세션 클릭/점프 시 Claude 데스크톱 앱 지원 (공식 claude:// URI 호출 및 Claude.exe 윈도우 감지·SW_RESTORE·최상단 포커스)
- 설정(시스템 탭)에 '세션 클릭 시 이동 대상' 선택 옵션(자동 감지 / VS Code / Claude 데스크톱 앱 / 기본 터미널) 탑재
- 세션 이동 버튼 툴팁 및 안내 문구를 '작업 창(VS Code · Claude 데스크톱 · 터미널)'으로 통합
- 산책모드 좌우 이동 속도 완화(0.7px ➔ 0.28px/f) 및 발걸음 주기(220ms ➔ 420ms) 조정으로 시각적 촐랑거림 해소
- 산책모드 미니미 크기 슬림화(설정 위젯 크기와 연동: 크게 2.1배, 보통 1.75배, 작게 1.45배) 및 창 높이 축소(110px/98px/88px)
- 설정(⚙️) 메뉴 목적별 7대 카테고리(화면&테마, 바탕화면 위젯, 코딩 BGM, 직원&팀, 인테리어&펫, 알림&휴대폰, 시스템&연동) 전면 개편
- 상단 HUD 버튼 그룹화(도구 캡슐: 검색·위젯·코인 / 제어 캡슐: 창고정·더보기·설정)로 시각적 복잡도 해소
- 더보기(⋯) 드롭다운 메뉴 3대 영역(업무&보기, 오피스 라이프, 안내&바로가기) 체계적 분류 및 상점 바로가기 추가
- 세션(직원) 출근 시 남/녀 50:50 자동 랜덤 생성 및 성별 전용 헤어/외형 그래픽 렌더링
- 직원 상세 패널 모습 커스텀 바에 성별 토글 버튼([👦 남] ⇄ [👧 여]) 탑재 및 실시간 전환 지원
- 성별 변경 시 서브화면(미니위젯, 미니바, 산책모드) 및 메인 캔버스 즉시 새로고침 동기화(IPC 메시지 연동)
- 설정(직원 탭)에 '직원 성별' 옵션(랜덤/남자/여자) 및 안전 확인 경고창(Confirm) 탑재
- 서브화면 모드 변경 아이콘 단일화(🔄)
- Claude Code 연결 기본값 '활성화(연결 상태)' 전면 보장 및 최초 실행 모드 선택 모달 스크린샷 탑재
