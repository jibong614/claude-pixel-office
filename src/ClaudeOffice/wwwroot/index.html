      🖥️ 1. [지금 터미널로 이동] 클릭
      해당 직원의 VS Code / 터미널 창으로 화면이 자동 전환되고 위 내용이 클립보드에 준비됩니다.
      2
      ⌨️ 2. 터미널 창에서 Ctrl+V 후 Enter 실행
      별도로 복사하지 않아도 클립보드에 이미 들어 있으니, 입력창에 그대로 붙여넣고 Enter를 누르세요.

      Claude의 첫 답변이 끝나면 연결이 완료되어, 다음부터는 터미널로 이동할 필요 없이 오피스나 미니펫에서 바로 지시가 전달됩니다!
