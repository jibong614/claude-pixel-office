      ❓ 세션이 안 보여요 — 원인 & 해결 Q&A

      Claude 데스크톱(MCP) 또는 Claude Code(터미널) 세션이 사무실에 나타나지 않을 때 확인해 보세요.
      Claude 데스크톱 (MCP) Q. Claude 데스크톱 앱에서 작업 중인데 직원이 출근하지 않아요

      Claude 데스크톱은 MCP(Model Context Protocol)를 통해 Pixel Office에 상태를 보고합니다. 아래 3가지를 확인해 주세요:

      • 1. 프로젝트 지침(Instructions) 등록 필수:
        Claude 데스크톱의 프로젝트 설정에서 [지침(Instructions)] 편집창에 가이드의 연동 지침 프롬프트를 붙여넣으셔야 Claude가 상태를 보고합니다.
      • 2. 첫 호출 시 [항상 허용(Always allow)] 선택:
        채팅방에서 첫 질문 후 office_report_status 도구 권한 팝업이 뜰 때 반드시 [항상 허용]을 눌러주셔야 매번 멈추지 않고 자동으로 출근합니다.
      • 3. Claude 데스크톱 완전 재시작:
        설정 적용 후 작업표시줄 오른쪽 트레이(▲)에서 Claude 아이콘을 우클릭하고 [Quit] 후 다시 켜야 연동이 활성화됩니다.
      화면 캡처와 지침 복사가 필요하신가요?
      Claude Code (터미널) Q. 터미널이나 VS Code에서 Claude Code를 켰는데 직원이 안 나와요
      • 첫 질문(프롬프트)을 전송했나요?
        터미널에서 claude 명령을 켜기만 한 상태에서는 세션 기록 파일이 생성되지 않습니다. 아무 질문이나 첫 프롬프트를 1회 전송해야 비로소 출근합니다.
      • 표시 기간 설정 확인:
        ⚙️ 설정 → 직원 & 팀 → 표시 기간을 확인하세요. 기본 설정 시간(예: 24시간)보다 오래된 세션은 자동으로 퇴근합니다. 기간을 '전체(7일)'로 늘려보세요.
      • Claude Code 연결(Hooks) 확인:
        ⚙️ 설정 → 시스템 & 연동 탭에서 [Claude Code 연결]이 켜져 있는지 확인하세요.
      자동 퇴근 안내 Q. 일하던 직원이 갑자기 자리에서 사라졌어요 (퇴근)

      대화 세션에서 3시간 이상 추가 질문이나 작업이 없으면 직원은 편안히 휴식하기 위해 자동 퇴근(🚪) 처리됩니다.

      💡 해당 터미널이나 Claude 데스크톱 프로젝트에서 다시 질문이나 지시를 보내면 즉시 출근하여 책상에 앉습니다!

      화면 모드 Q. 여러 세션을 실행 중인데 사무실에 일부만 보여요

      사무실 책상 자리가 가득 차거나 창 크기에 따라 일부 직원이 보이지 않을 수 있습니다. 상단 바의 [🏢 오피스 모드] 버튼을 누르면 대시보드 리스트 형태로 전체 세션을 한눈에 확인하고 제어할 수 있습니다.

      >

      📡 세션 최초 1회 연결 안내

      이 세션에 오피스에서 지시를 보내려면 최초 1회 터미널 연결이 필요합니다.

      새로 시작된 세션은 터미널에서 최소 1회 명령이 실행되어야 오피스 감시 훅과 실시간으로 연결됩니다.

      📋 클립보드에 자동 복사된 내용 (미리보기):
      "안녕" (연결 약속어)
      💡 사용자가 직접 복사할 필요 없이 오피스가 이미 복사해 두었습니다. 터미널 창에서 바로 [Ctrl+V]를 누르고 [Enter]를 실행하세요.
      1
      🖥️ 1. [지금 터미널로 이동] 클릭
      해당 직원의 VS Code / 터미널 창으로 화면이 자동 전환되고 위 내용이 클립보드에 준비됩니다.
      2
      ⌨️ 2. 터미널 창에서 Ctrl+V 후 Enter 실행
      별도로 복사하지 않아도 클립보드에 이미 들어 있으니, 입력창에 그대로 붙여넣고 Enter를 누르세요.
      3
      ✅ 3. 실시간 연결 완료!
      Claude의 첫 답변이 끝나면 연결이 완료되어, 다음부터는 터미널로 이동할 필요 없이 오피스나 미니위젯에서 바로 지시가 전달됩니다!
