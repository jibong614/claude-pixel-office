# 휴대폰에서 보기 — 처음 설정 (한 번만, 10분쯤)

PC의 Claude Office가 **화면용 요약만 암호화해서** 내 구글 Firebase(무료)에 올리고, 휴대폰은 QR로 연 웹페이지에서 받아 봅니다.
휴대폰에는 로그인이 필요 없고, 밖(LTE)에서도 됩니다. 보기 전용입니다.

필요한 것: 구글 계정 1개. (Node.js·명령어 입력은 필요 없습니다)

## 앱 안의 설정 도우미를 따라 하세요
Claude Office **⚙️ → 휴대폰에서 보기 → [설정 도우미]** 를 누르면 아래 6단계가 차례로 나옵니다.
단계마다 **[열기]** 버튼이 Firebase 콘솔의 그 화면을 바로 열어 주고, 마치면 앱이 **저절로 확인해 ✓** 를 붙입니다
(도우미를 열어 두면 5초마다 다시 확인). 막히면 그 단계에 무엇이 문제인지 주황색 글로 나옵니다.

| 단계 | 할 일 | 앱이 확인하는 것 |
|---|---|---|
| 1. 프로젝트 만들기 | [Firebase 콘솔](https://console.firebase.google.com) → 프로젝트 만들기. 이름은 아무거나, 애널리틱스는 꺼도 됨, 요금제는 무료(Spark) 그대로 | — |
| 2. 웹 앱 등록 → 설정 붙여넣기 | 프로젝트 첫 화면의 웹(`</>`) 버튼 → 앱 등록 → 나오는 `firebaseConfig` 블록을 통째로 복사해 도우미 칸에 붙여 넣고 [저장] | apiKey·projectId |
| 3. Realtime Database 만들기 | Realtime Database → 데이터베이스 만들기. 위치는 싱가포르(asia-southeast1), 규칙은 "잠금 모드로 시작" | 데이터베이스 주소를 **프로젝트 ID로 저절로 찾음**(붙여 넣을 필요 없음) |
| 4. 보안 규칙 붙여넣기 | 도우미의 [규칙 복사] → Realtime Database **규칙** 탭 내용을 모두 지우고 붙여 넣기 → [게시] | 휴대폰이 읽을 칸은 열려 있고, 전체 목록은 막혀 있는지 |
| 5. 익명 로그인 켜기 | Authentication(보안 또는 빌드 메뉴 아래) → 시작하기 → 로그인 방법 → **익명** → 사용 설정 → 저장 | PC가 로그인할 수 있는지 |
| 6. 켜고 QR 찍기 | [켜기] → [QR 보기] → 휴대폰 카메라로 찍기 | 올리기가 되는지, 휴대폰 페이지가 열리는지 |

- 2단계 설정에 `databaseURL` 이 없어도 괜찮습니다(데이터베이스보다 웹 앱을 먼저 만들면 빠져 있음) — 3단계에서 앱이 찾습니다.
- 4단계 규칙은 저장소의 [`mobile/database.rules.json`](../mobile/database.rules.json)과 같습니다: `offices/<내 ID>` 는 누구나 읽을 수 있지만(내용은 암호문뿐, ID를 알아야 함) 쓰기는 PC가 로그인한 자기 칸에만.
  "누구나 읽고 쓸 수 있는 규칙(테스트 모드)"이면 앱이 ⚠️ 로 알려 줍니다.
- 5단계의 **"익명 계정 자동 정리(30일)"**(Identity Platform 업그레이드 때 나오는 설정)는 **켜지 마세요** — 30일마다 PC의 익명 계정이 지워져 QR을 다시 찍어야 합니다.

## 휴대폰 페이지 — 공용 페이지 / 내 Hosting
휴대폰이 여는 페이지는 기본으로 **공용 페이지**(`https://jibong614.github.io/claude-pixel-office/`)입니다.
이 저장소의 화면 파일(`src/ClaudeOffice/wwwroot`)을 GitHub Pages 에 그대로 올린 것으로, 모두에게 같은 파일입니다.
**내 데이터 주소와 해독 키는 QR 주소의 `#` 뒤에만** 있고 `#` 뒤는 웹 서버로 전송되지 않으므로, 페이지를 따로 올릴 필요가 없습니다.

직접 올린 페이지를 쓰고 싶다면(공용 페이지를 믿고 싶지 않을 때 등):
1. Node.js 를 설치하고 PowerShell 에서 한 번 `npx --yes firebase-tools login`
2. 저장소 폴더에서 `powershell -File tools\deploy-mobile.ps1` — 화면 파일을 내 Firebase Hosting(`https://<프로젝트ID>.web.app`)에 올리고 규칙도 함께 올립니다
3. ⚙️ → 휴대폰에서 보기 → **휴대폰 페이지: 내 Firebase Hosting** → 휴대폰에서 QR 다시 찍기

## 휴대폰에서 별명·메모 고치기 (선택)
⚙️ → 휴대폰에서 보기 → **휴대폰에서 별명·메모 고치기**를 켜면 휴대폰의 직원 상세에서 별명·메모를 고칠 수 있습니다.
- 휴대폰은 고친 것을 **같은 키로 암호화해** 데이터베이스 `inbox/<내 ID>` 에 남기기만 하고(추가만 가능, 읽기·덮어쓰기 불가), PC가 몇 초 안에 가져가 해독·반영한 뒤 지웁니다. 해독이 안 되는 것은 버립니다.
- **1.0.9 전에 규칙을 붙여 넣었다면 규칙을 새로 붙여 넣어야 합니다**(4단계 [규칙 복사] → 규칙 탭에 붙여 넣고 게시). 예전 규칙이면 휴대폰에 "보내지 못했어요"가 뜨고, 점검·설정 도우미 4단계가 ⚠️ 로 알려 줍니다.
- PC가 꺼져 있으면 켜질 때 반영합니다(남긴 것은 그대로 기다림).

## 휴대폰에서 지시·승인 — 자리 비움 원격 (선택, 1.1.0)
⚙️ → 자리 비움 원격 → **[연결하기]** 를 하고, 자리를 뜰 때 PC에서 **🏃 자리 비움**을 켜거나 화면을 잠그세요(⊞+L).
휴대폰의 직원 상세에 **🏃 자리 비움 원격** 칸이 생깁니다.
- ✋ **승인 요청**: 명령 원문을 보고 [승인]·[거절]. 거절할 때 "대신 할 일"을 쓰면 Claude가 그대로 따릅니다
- **지시 보내기**: 쉬던 세션이 깨어나 같은 대화에서 이어서 일합니다. 직원 상세에 `📡 연결됨`이 보여야 바로 전해집니다(이미 열려 있던 세션은 원격을 연결한 뒤 한 번 더 답을 마쳐야 연결)
- 💬 **마지막 답**: Claude가 마지막으로 한 답 — 원격을 연결하면 이것도 암호화한 요약에 실립니다
- 휴대폰이 보내는 것은 별명·메모와 같은 `inbox/<내 ID>` 통로라 **1.0.9 의 새 규칙**이 필요합니다(4단계)
- 자리 비움은 PC에서만 켤 수 있고, 꺼져 있으면 휴대폰 지시는 버리고 승인은 PC 승인 창으로 갑니다. 받은 것은 모두 데이터 폴더의 `remote.log` 에 남습니다
- QR·주소를 가진 사람은 자리 비움 동안 이 PC의 Claude에게 일을 시킬 수 있습니다 — 남이 봤다면 **키 새로 만들기**

## 앱으로 설치하기 (주소창 없이)
- **안드로이드 크롬**: QR로 연 화면에서 메뉴(⋮) → **앱 설치**(또는 "홈 화면에 추가" → **설치**). "바로가기 만들기"는 주소창이 보이는 바로가기라 **설치**를 고르세요
- **아이폰 사파리**: 공유 버튼 → **홈 화면에 추가**
- QR로 처음 열 때 연결 정보(데이터 주소·해독 키)가 **그 휴대폰에 저장**되고 주소창에서는 키가 지워집니다. 설치한 앱은 그 정보로 바로 보입니다.
  PC에서 **키 새로 만들기**를 했거나 휴대폰 페이지를 바꿨다면 QR을 한 번 다시 찍으세요.
- 연결 정보가 없는 기기에서 열면 "📱 PC와 아직 이어지지 않았어요 — QR을 찍어 주세요"가 나옵니다.

## 무엇이 올라가나 (보안)
- 올라가는 것: 화면에 보이는 요약 — 직원(세션) 이름·상태·말풍선, 마지막 지시, 최근 작업 목록, 작업 폴더 경로, 사무실 이름, 별명·메모.
  **PC에서 AES-256-GCM 으로 암호화한 뒤** 올라가므로 Firebase 에는 알아볼 수 없는 암호문만 있습니다.
- 올라가지 않는 것: 대화 원본(jsonl), 소스 코드, 명령 실행 결과
- 해독 키는 **QR 주소의 `#` 뒤에만** 있습니다. 휴대폰은 처음 연 뒤 키를 그 휴대폰의 브라우저 저장소에 보관합니다(설치한 앱이 쓰도록).
  QR이나 주소가 남에게 보였거나 휴대폰을 바꿨다면 **키 새로 만들기**(쓰던 휴대폰은 QR을 다시 찍어야 함)
- 휴대폰 페이지는 Firebase 주소(`*.firebaseio.com`, `*.firebasedatabase.app`)에만 연결합니다.
- 휴대폰에서 고치기·자리 비움 원격을 켜면 `inbox/<내 ID>` 에 누구나 **추가**는 할 수 있습니다(ID를 알아야 하고, 키 없이 만든 것은 PC가 해독하지 못해 버림).
- **끄면** 클라우드에 남은 요약도 지웁니다.
- PC가 꺼져 있거나 Claude Office가 닫혀 있으면 올라가지 않습니다. 정상적으로 끝내면 휴대폰에 바로 `💤 PC에서 꺼짐 · 시각`이,
  정전 등으로 소식이 끊기면 1분 반 뒤 `PC 응답 없음`이 뜨고 사무실이 흐려집니다(멈춘 모습).
- 늘 보려면 ⚙️ → 창 → **Windows 시작할 때 자동 실행**을 켜 두세요. ✕를 눌러도 꺼지지 않고 알림 영역(🏢)에 숨습니다.

## 이럴 땐
| 상태 문구 | 할 일 |
|---|---|
| 도우미 3단계 `아직 Realtime Database 가 없어요` | 데이터베이스를 만들었는지(같은 프로젝트인지) |
| 도우미 4단계 `아직 잠금 모드 규칙이에요` / ⚠️ `테스트 모드` | 규칙 탭에 [규칙 복사]한 것을 붙여 넣고 **게시** |
| `익명 로그인이 꺼져 있어요` | 5단계(Authentication 에서 "시작하기"를 먼저 눌러야 할 수도) |
| `apiKey 가 맞지 않습니다` | 2단계 설정을 다시 복사해 붙여 넣기 |
| `휴대폰 페이지가 열리지 않아요` | 인터넷 연결, 또는 "내 Firebase Hosting"을 골랐다면 `tools\deploy-mobile.ps1` |
| 휴대폰에 `해독하지 못했어요` | PC에서 키를 새로 만들었으면 QR을 다시 찍기 |
| 휴대폰에 `PC가 아직 아무것도 올리지 않았어요` | PC에서 켜기 |

언제든 ⚙️ → 휴대폰에서 보기 → **점검·설정 도우미** 로 지금 상태를 단계별로 다시 확인할 수 있습니다.

## 사용량
무료(Spark) 한도 안에서 충분합니다 — 요약은 한 번에 약 3~4KB, 바뀔 때만 최대 3초에 한 번, 그 밖에는 1분에 한 번 올립니다.
