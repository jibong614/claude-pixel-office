# 휴대폰에서 보기 — 처음 설정 (한 번만)

PC의 Claude Office가 **화면용 요약만 암호화해서** 구글 Firebase에 올리고, 휴대폰은 QR로 연 웹페이지에서 받아 봅니다.
휴대폰에는 로그인이 필요 없고, 밖(LTE)에서도 됩니다. 보기 전용입니다.

필요한 것: 구글 계정 1개, 이 PC의 Node.js(`C:\Program Files\nodejs`, 이미 설치됨)

## 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com → **프로젝트 추가(만들기)**
2. 이름 입력(예: `my-claude-office`) → Google 애널리틱스는 꺼도 됩니다 → 만들기
3. 요금제는 **무료(Spark)** 그대로 둡니다. 결제 정보는 필요 없습니다.

## 2. Realtime Database 만들기
1. 왼쪽 메뉴에서 **Realtime Database → 데이터베이스 만들기** (콘솔 버전에 따라 "빌드" 또는 "데이터베이스" 아래)
2. 위치: **싱가포르(asia-southeast1)** — 가까워서 빠릅니다
3. 보안 규칙: **잠금 모드로 시작** — 실제 규칙은 4단계에서 자동으로 올라갑니다

## 3. 익명 로그인 켜기
1. 왼쪽 메뉴 **보안(Security) → Authentication** (예전 콘솔에서는 "빌드(Build)" 아래에 있었음)
   바로가기: `https://console.firebase.google.com/project/<프로젝트ID>/authentication/providers`
2. 처음이면 **시작하기(Get started)** 를 한 번 누릅니다
3. **로그인 방법(Sign-in method)** 탭 → 제공업체 목록에서 **익명(Anonymous)** → **사용 설정** 스위치 → **저장**

PC의 Claude Office가 이 방법으로 로그인해 자기 칸에만 씁니다. 휴대폰은 로그인하지 않습니다.
※ "익명 계정 자동 정리(30일)"(Identity Platform 업그레이드 시 나오는 설정)는 **켜지 마세요** — 30일마다 PC의 익명 계정이 지워져 휴대폰에서 QR을 다시 찍어야 합니다.

## 4. 웹 앱 설정을 Claude Office에 붙여 넣기
1. 왼쪽 위 톱니 → **프로젝트 설정 → 일반 → 내 앱 → 웹(`</>`) 아이콘** → 앱 닉네임 입력 → 앱 등록
   (Firebase Hosting 체크는 안 해도 됩니다)
2. 화면에 나오는 `const firebaseConfig = { … };` 블록을 **통째로** 복사합니다.
   `databaseURL:` 줄이 있어야 합니다. 없으면 2단계를 마친 뒤 같은 화면에서 다시 복사하세요.
3. Claude Office **⚙️ → 휴대폰에서 보기 → 설정하기** → 붙여 넣기 → **저장** (아직 켜지 않아도 됩니다)

## 5. 휴대폰 화면 페이지와 데이터베이스 규칙 올리기
PowerShell에서(처음 한 줄은 처음 한 번만 — 브라우저가 열리면 같은 구글 계정으로 로그인):

```powershell
& "C:\Program Files\nodejs\npx.cmd" --yes firebase-tools login
powershell -File tools\deploy-mobile.ps1   # 저장소 폴더에서
```

`완료 — 휴대폰 화면 주소: https://<프로젝트ID>.web.app` 이 나오면 됩니다.
Claude Office를 새 버전으로 바꿨을 때 휴대폰 화면도 맞추려면 두 번째 줄만 다시 실행하세요.

## 6. 켜고 휴대폰으로 열기
1. Claude Office **⚙️ → 휴대폰에서 보기 → 켜기** → 상태가 `📡 올리는 중 · 마지막 …` 이 되면 성공
2. **QR 보기** → 휴대폰 카메라로 찍어 열기
   — 이때 연결 정보(데이터 주소·해독 키)가 **휴대폰에 저장**되고, 주소창에서는 키가 지워집니다

휴대폰 화면 맨 위에 `📡 실시간`이 보이면 PC와 이어진 것입니다(PC에서 바뀌면 몇 초 안에 반영).

## 7. 앱으로 설치하기 (주소창 없이)
- **안드로이드 크롬**: QR로 연 화면에서 메뉴(⋮) → **앱 설치**(또는 "홈 화면에 추가" → **설치**)
  - "바로가기 만들기"는 주소창이 보이는 바로가기라 **설치**를 고르세요
  - 예전에 만든 바로가기가 있으면 지우고 다시 설치하세요
- **아이폰 사파리**: 공유 버튼 → **홈 화면에 추가**
- 설치한 앱은 주소 없이 열리지만, 2번에서 휴대폰에 저장한 연결 정보를 써서 바로 보입니다.
  PC에서 **키 새로 만들기**를 했다면 QR을 한 번 다시 찍으면 됩니다(설치한 앱도 새 키를 씁니다).
- 연결 정보가 없는 기기에서 열면 "📱 PC와 아직 이어지지 않았어요 — QR을 찍어 주세요"가 나옵니다.

## 무엇이 올라가나 (보안)
- 올라가는 것: 화면에 보이는 요약 — 직원(세션) 이름·상태·말풍선, 마지막 지시, 최근 작업 목록, 작업 폴더 경로, 사무실 이름, 별명·메모.
  **PC에서 AES-256으로 암호화한 뒤** 올라가므로 구글(Firebase)에는 알아볼 수 없는 암호문만 있습니다.
- 올라가지 않는 것: 대화 원본(jsonl), 소스 코드, 명령 실행 결과
- 해독 키는 **QR 주소의 `#` 뒤에만** 있습니다. `#` 뒤는 웹 서버로 전송되지 않습니다.
  휴대폰은 처음 연 뒤 키를 그 휴대폰의 브라우저 저장소에 보관합니다(설치한 앱이 쓰도록).
  QR이나 주소가 남에게 보였거나 휴대폰을 바꿨다면 **키 새로 만들기**(그 뒤 쓰던 휴대폰은 QR을 다시 찍어야 함)
- **끄면** 클라우드에 남은 요약도 지웁니다.
- PC가 꺼져 있거나 Claude Office가 닫혀 있으면 올라가지 않습니다. Claude Office를 정상적으로 끝내면 휴대폰에 바로
  `💤 PC에서 꺼짐 · 시각`이, 정전 등으로 소식이 끊기면 1분 반 뒤 `PC 응답 없음`이 뜨고 사무실이 흐려집니다(멈춘 모습).
- 늘 보려면 ⚙️ → 창 → **Windows 시작할 때 자동 실행**을 켜 두세요. ✕를 눌러도 꺼지지 않고 알림 영역(🏢)에 숨습니다.

## 이럴 땐
| 상태 문구 | 할 일 |
|---|---|
| `Firebase 콘솔 → Authentication … '익명'을 켜 주세요` | 3단계 |
| `데이터베이스가 쓰기를 거부했습니다 — 규칙을 올렸는지 확인` | 5단계(규칙이 아직 안 올라감) |
| `데이터베이스를 찾지 못했습니다` | 2단계를 했는지, 붙여 넣은 설정에 `databaseURL` 이 있는지 |
| `apiKey 가 맞지 않습니다` | 4단계의 설정을 다시 복사해 붙여 넣기 |
| 휴대폰에 `해독하지 못했어요` | PC에서 키를 새로 만들었으면 QR을 다시 찍기 |
| 휴대폰에 `PC가 아직 아무것도 올리지 않았어요` | PC에서 켜기 |
| 휴대폰 페이지가 안 열림(404) | 5단계 |

## 사용량
무료(Spark) 한도 안에서 충분합니다 — 요약은 한 번에 약 3~4KB, 바뀔 때만 최대 3초에 한 번, 그 밖에는 1분에 한 번 올립니다.
