# 휴대폰 연결 — 켜고 QR 한 번

PC의 Claude Office가 **화면용 요약만 잠가서** 무료 서버로 보내고, 휴대폰은 QR로 연 웹페이지에서 받아 봅니다.
휴대폰에는 로그인이 필요 없고, 밖(LTE)에서도 됩니다. 구글 계정·Firebase 프로젝트 같은 준비는 없습니다.

## 켜기
1. Claude Office **⚙️ → 📱 휴대폰 → 휴대폰 연결 [켜기]**
2. **[QR 보기]** → 휴대폰 카메라로 찍기
3. 끝. 홈 화면에 앱으로 설치하면 다음부터는 바로 열립니다(아래 "앱으로 설치하기")

## 무료 서버 — 남이 볼 수 있나요?
아니요. 무료 서버는 **잠긴 상자를 전해 주기만** 합니다.
- 휴대폰 화면: 이 저장소의 화면 파일을 GitHub Pages 에 그대로 올린 공용 페이지(`https://jibong614.github.io/claude-pixel-office/`) — 모두에게 같은 파일
- 전달: Google Firebase(무료 요금제) — 이 프로그램을 쓰는 모두가 함께 쓰지만, 각 PC는 자기 칸(`offices/<내 ID>`)에만 쓸 수 있습니다
- PC가 요약을 **AES-256-GCM 으로 잠가서** 보내고, 열쇠는 **QR 주소의 `#` 뒤에만** 있습니다. `#` 뒤는 웹 서버로 전송되지 않으므로
  **서버도, 함께 쓰는 다른 사용자도 내용을 열 수 없습니다.** 서버에는 알아볼 수 없는 암호문만 있습니다
- 규칙은 저장소의 [`mobile/database.rules.json`](../mobile/database.rules.json) 그대로입니다: 칸 목록은 아무도 못 보고, 내 칸은 ID를 아는 사람만 읽을 수 있으며(암호문뿐) 쓰기는 PC가 로그인한 자기 칸에만
- 무료 한도 안에서 운영합니다 — 쓰는 사람이 아주 많아 한도를 넘으면 잠시 멈출 수 있지만, 요금은 나오지 않습니다

## 휴대폰에서 별명·메모 고치기
휴대폰의 직원 상세에서 별명·메모를 고칠 수 있습니다(⚙️ → 📱 휴대폰 → 고급에서 끌 수 있음).
- 휴대폰은 고친 것을 **같은 열쇠로 잠가** `inbox/<내 ID>` 에 남기기만 하고(추가만 가능, 읽기·덮어쓰기 불가), PC가 몇 초 안에 가져가 열어서 반영한 뒤 지웁니다. 열리지 않는 것은 버립니다.
- PC가 꺼져 있으면 켜질 때 반영합니다(남긴 것은 그대로 기다림).

## 자리를 비웠을 때 — 휴대폰에서 지시·승인
Claude Code와 연결해 두면(처음 켤 때 묻는 창, 또는 ⚙️ → 🖥️ 일반 → Claude Code 연결) **그냥 자리를 뜨고 휴대폰으로 사무실을 열면 됩니다.** 누를 버튼은 없습니다.
- PC를 30초 넘게 안 쓰는 동안 휴대폰 화면이 열려 있으면 그때부터 지시·승인이 휴대폰으로 옵니다(= 자리 비움). 돌아와 마우스·키보드를 움직이면 PC로 돌아갑니다
- 휴대폰을 안 보고 있어도 입력이 3분(설정에서 바꿈) 없거나 화면을 잠그면(⊞+L) 자리 비움 — 그 사이 온 승인 요청은 휴대폰을 열 때까지 기다립니다(최대 55분, 넘으면 PC 승인 창)

휴대폰의 직원 상세에 **📱 휴대폰 지시·승인** 칸이 생깁니다.
- ✋ **승인 요청**: 명령 원문을 보고 [승인]·[거절]. 거절할 때 "대신 할 일"을 쓰면 Claude가 그대로 따릅니다
- **지시 보내기**: 쉬던 세션이 깨어나 같은 대화에서 이어서 일합니다. 직원 상세에 `📡 연결됨`이 보여야 바로 전해집니다(연결하기 전부터 열려 있던 세션은 한 번 더 답을 마쳐야 연결 · Claude Office를 껐다 켜도 15초 안에 다시 붙음)
- 💬 **마지막 답**: Claude가 마지막으로 한 답 — 이것도 잠근 요약에 실립니다
- 누가 PC를 쓰고 있으면(마지막 입력이 30초 안) 휴대폰은 자리 비움을 켤 수 없고, 그때 보낸 지시는 버리며 승인은 PC 승인 창으로 갑니다. 받은 것은 모두 데이터 폴더의 `remote.log` 에 남습니다
- QR·주소를 가진 사람은 자리 비움 동안 이 PC의 Claude에게 일을 시킬 수 있습니다 — 남이 봤다면 **키 새로 만들기**

## 앱으로 설치하기 (주소창 없이)
- **안드로이드 크롬**: QR로 연 화면에서 메뉴(⋮) → **앱 설치**(또는 "홈 화면에 추가" → **설치**). "바로가기 만들기"는 주소창이 보이는 바로가기라 **설치**를 고르세요
- **아이폰 사파리**: 공유 버튼 → **홈 화면에 추가**
- QR로 처음 열 때 연결 정보(데이터 주소·열쇠)가 **그 휴대폰에 저장**되고 주소창에서는 열쇠가 지워집니다. 설치한 앱은 그 정보로 바로 보입니다.
  PC에서 **키 새로 만들기**를 했다면 QR을 한 번 다시 찍으세요.
- 연결 정보가 없는 기기에서 열면 "📱 PC와 아직 이어지지 않았어요 — QR을 찍어 주세요"가 나옵니다.

## 무엇이 올라가나
- 올라가는 것: 화면에 보이는 요약 — 직원(세션) 이름·상태·말풍선, 마지막 지시, 최근 작업 목록, 작업 폴더 경로, 사무실 이름, 별명·메모(Claude Code와 연결했다면 Claude의 마지막 답도). 모두 **PC에서 잠근 뒤** 올라갑니다
- 올라가지 않는 것: 대화 원본(jsonl), 소스 코드, 명령 실행 결과
- 휴대폰은 처음 연 뒤 열쇠를 그 휴대폰의 브라우저 저장소에 보관합니다(설치한 앱이 쓰도록). QR이나 주소가 남에게 보였거나 휴대폰을 바꿨다면 **키 새로 만들기**(쓰던 휴대폰은 QR을 다시 찍어야 함)
- 휴대폰 페이지는 Firebase 주소(`*.firebaseio.com`, `*.firebasedatabase.app`)에만 연결합니다
- **끄면** 서버에 남은 요약도 지웁니다
- PC가 꺼져 있거나 Claude Office가 닫혀 있으면 올라가지 않습니다. 정상적으로 끝내면 휴대폰에 바로 `💤 PC에서 꺼짐 · 시각`이,
  정전 등으로 소식이 끊기면 1분 반 뒤 `PC 응답 없음`이 뜨고 사무실이 흐려집니다(멈춘 모습)
- 늘 보려면 ⚙️ → 🖥️ 일반 → **Windows 시작할 때 자동 실행**을 켜 두세요. ✕를 눌러도 꺼지지 않고 알림 영역(🧑‍💻)에 숨습니다

## 이럴 땐
| 상태 문구 | 할 일 |
|---|---|
| PC 설정에 `📦 무료 서버로 옮겼어요` | 휴대폰에서 QR을 한 번 다시 찍기 |
| PC 설정에 `무료 서버에 로그인하지 못했어요` / `쓰기를 거부했어요` | 인터넷 연결 확인 — 30초마다 저절로 다시 해 봅니다 |
| 휴대폰에 `해독하지 못했어요` | PC에서 키를 새로 만들었으면 QR을 다시 찍기 |
| 휴대폰에 `PC가 아직 아무것도 올리지 않았어요` | PC에서 휴대폰 연결 켜기 |
| 휴대폰 설정 맨 위에 `휴대폰 화면이 PC 앱보다 옛 버전` | 휴대폰 새로고침(앱으로 설치했다면 완전히 닫았다 열기) |

## 사용량
요약은 한 번에 약 3~4KB, 바뀔 때만 최대 3초에 한 번, 그 밖에는 1분에 한 번 올립니다.

## 예전 버전에서 옮겨 올 때
- 1.1.6 까지 **내 Firebase 프로젝트**로 쓰던 분은 업데이트하면 저절로 무료 서버로 옮겨집니다(설정에 `📦 무료 서버로 옮겼어요`) — 휴대폰에서 QR을 **한 번 다시** 찍으세요.
  내 프로젝트는 더 쓰지 않으니 Firebase 콘솔에서 지워도 됩니다.
- 1.1.8 이하에서 업데이트한 직후에는, 그때 쉬고 있던 세션이 한 번 더 답을 마쳐야 휴대폰 지시를 받을 수 있습니다(1.1.9 부터는 껐다 켜도 저절로 다시 붙음).
