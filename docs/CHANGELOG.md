  - **해결 조치**:
    - index.html: 뷰포트 메타태그에 maximum-scale=1.0, user-scalable=no, viewport-fit=cover를 명시하여 화면 회전 시 브라우저가 임의로 축소 배율을 유지하지 못하도록 고정
    - office.css: html, body에 width: 100%; max-width: 100vw; overflow-x: hidden; -webkit-text-size-adjust: 100%;를 적용하고 canvas#office에 max-width: 100%;를 부여하여 화면 너비를 초과하는 요소에 의한 축소 왜곡 원천 차단
    - office.js: orientationchange 및 isualViewport 이벤트 리스너를 연동하고, 회전 애니메이션 완료 후(120ms, 300ms) 뷰포트 레이아웃(layoutKey = ''), 상단 HUD 높이(--hud-h), 서랍 동기화(syncDrawers())를 정확하게 갱신하도록 안정화

    - `StartMinimized: true` 및 `Pet: true` 환경에서 시작 시 메인 창은 숨겨진 상태로 위젯 창(`WidgetWindow`)이 먼저 WebView2 환경(`CoreWebView2Environment`)을 생성하고 브라우저 프로세스를 구동
    - 이후 위젯 또는 트레이에서 메인 창을 처음 열 때(`ShowFromTray() -> Show() -> Loaded -> OnLoaded()`), 메인 창이 동일한 UserDataFolder 에 대해 별도의 `CoreWebView2Environment`를 다시 생성하면서 기존 브라우저 프로세스와의 COM 파이프 충돌로 `0x80010108 (RPC_E_DISCONNECTED)` 예외 발생
    - `OnLoaded()`에서 `WebView2RuntimeNotFoundException`만 catch하고 있어 처리되지 않은 COMException이 디버거로 전파

    - 프로세스 내 모든 창(메인창·위젯창·설정창)이 동일한 `CoreWebView2Environment` 인스턴스를 공유하도록 아키텍처 개선
    - `MainWindow`, `WidgetWindow`, `SettingsWindow` 전체에 걸쳐 공유 환경 적용
  - **RPC_E_DISCONNECTED 자동 복구 재시도 & 예외 안전망 확보**:
    - `COMException` (HResult `0x80010108`) 발생 시 `App.ResetSharedEnvironment()` 후 즉시 1회 자동 재연결 시도
    - 일반 `Exception` 캐치 및 안전한 null 체크 가드로 앱 비정상 종료 방지
