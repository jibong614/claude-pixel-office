## 1.0.5 — 2026-10-28
- **알림 영역(🏢) 아이콘**: 누르면 창 열기, 오른쪽 클릭 → 열기·끝내기. 마우스를 올리면 창 제목(✋ 개수 포함)
- 설정 "**닫기(✕)를 눌러도 끄지 않고 숨기기**"(기본 켜짐) — ✕는 창만 숨기고 감시·휴대폰 보기는 계속. 처음 숨길 때 한 번 안내 풍선
- 설정 "**Windows 시작할 때 자동 실행**" — 이 사용자 계정의 시작 프로그램(HKCU\…\Run)에 `--autostart` 로 등록, 자동 실행 때는 늘 알림 영역에 숨긴 채
- "프로그램 시작 시 작업표시줄로 이동"은 이제 창을 아예 띄우지 않고 알림 영역에 숨김(화면은 처음 열 때 준비)
- **중복 실행 방지**: 이미 켜져 있으면 새로 켜지 않고 그 창을 연다. `ClaudeOffice.exe --exit` 로 켜져 있는 것을 정상 종료
- **휴대폰에 "💤 PC에서 꺼짐 · 시각"**: 정상 종료 때 Firebase 에 꺼짐 시각을 덧붙여 바로 알림. 꺼졌거나 1분 반 넘게 소식이 없으면 사무실을 흐리게(멈춘 모습)
- 도구: pagetest·capture 는 `--exit` 로 시험 앱을 정상 종료, 가짜 서버 PATCH 지원, `CLAUDEOFFICE_RUN_KEY` 로 시작 프로그램 등록을 시험용 키에

## 1.0.4 — 2026-10-28
- 설정 "**프로그램 시작 시 작업표시줄로 이동**"(창 섹션): 켜 두면 다음 실행부터 창을 띄우지 않고 최소화로 켜짐. 감시·휴대폰 업로드는 그대로
  - 창이 뜨기 전에 알아야 해서 처음으로 앱 쪽 설정 파일 `app.json`(데이터 폴더)에 저장
  - 감시·훅·휴대폰 업로드를 화면(WebView2)이 뜨기를 기다리지 않고 창을 만들 때 바로 시작
- **머리 위 말풍선을 되도록 한글로**: Claude가 영어로 쓴 명령 설명·검색어·인턴 일 대신 명령 종류에 맞는 한글 문구
  (예: dotnet build → 빌드하는 중, git status → 변경 내역 보는 중, python → 파이썬 실행 중). 원래 설명은 상세 패널 최근 작업에 남김
  - 인턴 이름도 한글(general-purpose → 일반 인턴, Explore → 탐색 인턴 …)
- 점검용 `--offscreen`: 창을 화면 밖에, 포커스·작업표시줄 없이 띄움. `capture.ps1`·`pagetest.ps1` 이 이것을 써서 **시험 중 창이 작업 화면에 뜨지 않음**
  - `capture.ps1` 은 화면을 긁지 않고 PrintWindow 로 창 내용을 직접 캡처, 임시 데이터 폴더 사용
- 고침: `pagetest.ps1` 에서 단계가 하나뿐이면 첫 글자만 실행되던 것, 툴팁의 "인턴 일반 인턴" 중복

## 1.0.3 — 2026-10-28
- 휴대폰 화면을 **앱으로 설치**(주소창 없이 열림): 웹 앱 정보(manifest)·아이콘(192·512·둥근 아이콘용·아이폰용)·서비스 워커
- QR로 처음 열 때 연결 정보를 휴대폰에 저장하고 주소창에서 키를 지움 → 설치한 앱(주소 # 없이 열림)도 그 정보로 바로 보임
- 연결 정보가 없는 기기에서 열면 견본 대신 "PC와 아직 이어지지 않았어요 — QR을 찍어 주세요"
- 고침: 이미 열린 화면에서 QR 주소(# 만 다름)로 가면 새 연결 정보가 반영되지 않던 것(키를 새로 만든 뒤 등)
- 도구: `tools/make-app-icons.ps1`, `pagetest.ps1` 의 `@cdp`(브라우저에 직접 묻기)·`@sleep`(페이지 밖에서 기다리기)·응답 없음 60초 제한

## 1.0.2 — 2026-10-28
- **휴대폰에서 보기**(밖에서도, 휴대폰 로그인 없이, 보기 전용) — 처음 설정은 [docs/MOBILE.md](MOBILE.md)
  - PC가 화면용 요약(+ 사무실 이름·별명·메모)만 gzip → AES-256-GCM 으로 암호화해 Firebase Realtime Database 에 올림(바뀔 때만 최대 3초에 한 번, 1분마다 생존 신호). 대화 원본은 올리지 않음
  - 휴대폰은 Firebase Hosting 의 같은 화면 페이지를 QR 주소로 열어 실시간 스트림으로 받고 기기 안에서 해독. 키는 주소 `#` 뒤에만
  - ⚙️ 설정 "휴대폰에서 보기": Firebase 설정 붙여넣기 / 켜기·끄기(끄면 클라우드의 요약도 지움) / QR 보기 / 주소 복사 / 키 새로 만들기
  - 휴대폰 화면: 상단 막대, 패널 전체 화면, PC 전용 설정(사무실 이름·표시 기간·항상 위·훅·휴대폰 보기)은 숨김, 별명·메모는 읽기 전용
- 도구: `tools/deploy-mobile.ps1`(페이지·규칙 배포), `tools/fake-rtdb.py`(Firebase 없이 시험), `pagetest.ps1 -Mobile -DataDir`
- 데이터 폴더를 `CLAUDEOFFICE_DATA_DIR` 로 바꿀 수 있음(점검 도구가 평소 설정·키를 건드리지 않게)

## 1.0.1 — 2026-10-28
- 오른쪽 패널(직원 상세·설정)을 펼치면 사무실이 남은 폭에 맞춰 다시 배치돼 **직원을 가리지 않음**
- 패널 접기·펼치기: 패널 왼쪽 가장자리 손잡이(›), 접으면 오른쪽 끝에 손잡이(‹ 직원 이름 / 설정)만 남고 사무실이 창 전체를 씀
  - 같은 직원을 다시 누르면 접기·펼치기, 접힌 설정은 ⚙️로 펼치기, ✕·Esc는 완전히 닫기
- 고침: 키 입력 대상이 문서 자체일 때 Esc 처리가 멈추던 것
