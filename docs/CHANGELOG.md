  - **마지막 답**: Claude 가 마지막으로 한 답을 휴대폰에서 봄

  - **자리 비움**은 PC 에서만: 상단 🏃 버튼·알림 영역 메뉴·**화면 잠금**(잠금을 풀면 저절로 꺼짐, 설정에서 끌 수 있음). 끄면 기다리던 승인은 PC 승인 창으로, 못 전한 지시는 버림
  - 휴대폰 → PC 는 별명·메모와 같은 통로(같은 키로 AES-256-GCM, inbox 추가만). 보낸 시각·일회용 값으로 10분 넘은 것·같은 것은 버림. 자리 비움 중에는 2초마다 가져옴
  - 받은 지시·승인·거절은 데이터 폴더 `remote.log` 에. PC 화면에서도 휴대폰을 기다리는 승인을 [여기서 처리]로 PC 승인 창에 띄울 수 있음
  - 기록 해석: 휴대폰 지시는 "📱 휴대폰 지시"로, 휴대폰 거절은 "휴대폰에서 거절"로 최근 작업에 남김
- 훅 수신기: 브라우저가 보낸 요청(Origin 헤더)은 받지 않음, 원격 요청은 `application/json` 만. 점검용 `CLAUDEOFFICE_HOOK_PORT`

## 1.0.9 — 2026-10-30
- **앱 안 업데이트**: 새 버전이 나오면(알림을 누르거나 ⚙️ → 정보 → [업데이트]) "업데이트할까요?" →
  켜진 채로 GitHub 릴리스 zip 받기(진행률) → 릴리스에 함께 올린 SHA-256 과 대조 → 풀기 → 지금 파일을 *.old 로 비켜 두고 새 것으로 바꾸기(실패하면 되돌림) → 새 버전 실행 → 옛 버전 종료.
  새 버전은 옛 버전이 끝나기를 기다렸다 켜지고 *.old 를 지운 뒤 "업데이트했어요" 알림. 업데이트 서버 없이 GitHub 만으로.
  개발용 빌드·쓰기 권한이 없는 폴더(Program Files 등)·해시 파일이 없는 옛 릴리스는 예전처럼 릴리스 페이지를 연다. 릴리스 자동 빌드가 `.zip.sha256` 도 올림
- **화면 영어**(⚙️ → 사무실 → 화면 언어 / Language): 화면·말풍선·알림·확인 창·설정 도우미까지 영어. 바꾸면 기록을 다시 읽어 말풍선도 바로 바뀜.
  휴대폰은 PC 언어를 따라감(요약에 lang). 견본·공용 페이지는 `?lang=en`. `watchtest --phrases N --en`
- **승인 후 오래 도는 명령도 "실행 중"으로**(훅 연결 시): 승인한 순간을 알려 주는 훅은 없어서, 명령 실행(Bash·PowerShell) 승인 대기 중
  그 명령(훅이 알려 준 tool_input.command)의 단어가 든 **프로세스가 요청 뒤에 새로 생기면** 승인된 것으로 보고 손을 내림(2초마다, 한 번에 수십 ms).
  알아보지 못하면(인코딩된 명령 등) 예전처럼 끝날 때 내림
- **휴대폰에서 별명·메모 고치기**(⚙️ → 휴대폰에서 보기, 켜야 동작): 휴대폰이 고친 것을 같은 키로 암호화해 `inbox/<ID>` 에 남기면(추가만 가능) PC가 4초마다 가져가 해독·반영하고 지움.
  고친 시각 기준으로 합침, 둘 다 지우면 별명·메모 삭제. **새 데이터베이스 규칙 필요** — 설정 도우미 4단계가 예전 규칙이면 ⚠️
- 고침: 휴대폰처럼 배율이 작은 화면에서 아랫줄 직원의 말풍선이 윗줄 이름표·상태 글을 가리던 것(그때만 책상 줄 간격을 넓힘)
- 도구: 가짜 Firebase 에 inbox(POST·GET·DELETE)
- 보안: 앱은 자기 화면(office.local)이 보낸 메시지만 받음(화면이 다른 주소로 옮겨 가도 그 페이지가 설정을 바꾸지 못하게)
